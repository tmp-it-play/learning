# Onboard: 습관 분석과 처방전

결과물은 gitignore된 `me/` 폴더의 네 파일이다. `/study` 는 매 세션 `me/prescription.md` 를 읽고 그대로 따른다. 방법론의 원칙은 `README.md` 의 "방법론"에 있다. 처방은 반드시 그 원칙 중 하나에 근거한다.

`me/prescription.md` 가 이미 있으면 먼저 읽고, 처음부터 다시 할지 바뀐 부분만 고칠지 묻는다.

## 1. 인터뷰

**한 번에 질문 하나**. 답이 모호하면 넘어가지 말고 구체적인 사례를 요구한다("최근에 그랬던 때를 하나 말해주세요"). 선택지가 자연스러운 질문만 `AskUserQuestion` 을 쓰고, 나머지는 자유 서술로 받는다.

1. **목표**: 왜 공부하나(취업·직무·연구 등), 강점으로 키우고 싶은 분야, 기한.
2. **과목과 현재 수준**: 공부할 과목 목록, 각각 어디까지 해봤는지. 수준이 애매하면 과목별로 짧은 퀴즈 2~3개로 확인한다.
3. **시간**: 하루에 쓸 수 있는 시간, 주당 공부일. 휴식을 뺀 순수 공부 분으로 환산해 확인받는다.
4. **습관**: "공부가 겉핥기로 끝나는 순간"을 사례로 받는다. 아래 영역을 하나씩 확인하고, 해당하는 것마다 계기와 원인을 2~3번 "왜?"로 파고든다.
   - 자료 선택: 같은 수준 자료 반복, 입문 자료로 회귀, 자료 쇼핑
   - 기록·정리: 정리에 시간 과다, 기록 안 함
   - 동기: "이게 도움이 될까?" 의심, 흥미 있는 것만, 쉽게 포기
   - 복습·기초: 복습 안 함, 기초 경시
   - AI 사용: 답만 받아 가기, 설명을 읽고 이해했다고 넘어가기
5. **선호와 제약**: 영어 자료 가능 여부, 이미 산 책·강의, 선호 매체(영상·글·구현).

모든 영역에 구체적인 답이 모이면 인터뷰를 끝낸다.

## 2. 진단과 처방

습관마다 **원인 → 근거 원칙 → 처방 → 검증 숫자** 를 쓴다.

- 처방은 `/study` 가 실제로 실행할 수 있는 행동이어야 한다(예: "틀리면 바로 교정", "확신도 기록 후 캘리브레이션 확인", "DAG 종점을 프로젝트에 두기").
- 도구로 바로 해결되지 않는 것(주로 동기)은 **가설**로 표시하고 체크포인트에서 검증하게 한다.
- 동기 문제가 있으면 앵커 프로젝트 트랙(만들면서 배우는 트랙)과 기초 트랙의 병행을 권한다.

## 3. 커리큘럼과 계획표

- **커리큘럼**: 트랙 → 단계. 단계마다 대상, **주 자료 하나**(이미 산 자료 우선, 영어 원문 우선, 블로그·입문 영상 제외), 끝낼 때 남길 결과물. 자료가 실제로 있는지 WebSearch/WebFetch로 확인하고 링크를 단다.
- **계획표**: 각 트랙의 **첫 단계만** 50~180분 단위 항목으로 쪼갠다. 다음 단계는 `/study` 가 그 단계에 도달했을 때 쪼갠다. 챕터·절 구성은 확인한 것만 쓰고, 확인 못 한 것은 사용자에게 알린다.

## 4. 승인 후 파일 생성

초안(처방 요약, 커리큘럼 개요, 계획표 앞부분, 설정)을 보여주고 승인받은 뒤에만 쓴다.

- `me/prescription.md`:
  ```
  # 처방전
  작성: <날짜> · 다시 쓰려면 /onboard
  ## 프로필          목표, 과목, 하루 예산과 트랙 비율, curriculum.md·plan.tsv 링크
  ## 습관 진단과 처방  ### N. <습관> → <처방 한 줄>  (원인, 근거 원칙, 처방 목록, 가설이면 표시)
  ## /study 지시      세션 중 Claude가 지킬 것 3~5줄 (피드백 방식, 피할 자료, DAG 종점)
  ```
- `me/curriculum.md`: 요약, 공부 규칙, 트랙별 단계, 주간 체크포인트, 선택적 확장.
- `me/plan.tsv`: 헤더 `id	track	stage	concept	title	source	est_min`. `stage` 는 노트 폴더 이름(kebab-case), `concept` 는 노트 파일 이름이 된다.
- `me/config.json`: `{"daily_min": <분>, "tracks": {"A": <비율>, ...}, "pass_pct": 80}`. 비율의 합은 1.
- `notes/<stage>/.gitkeep`: 커리큘럼 단계마다, 없는 폴더만 만든다.

마지막으로 `python3 tools/plan.py next` 를 실행해 첫 항목이 나오는지 확인하고, `/study` 로 시작하라고 안내한다.
